# Lista 03 de Exercícios ES6 2015

## Composição, Integração e Regras de Negócio

Esta lista tem como objetivo aplicar os conceitos de Programação Orientada a Objetos em cenários mais próximos de aplicações reais.

### Conceitos Trabalhados

* Composição de Objetos
* Relacionamento entre Classes
* Arrays de Objetos
* Manipulação de Coleções
* Regras de Negócio
* Interação entre Instâncias
* Lógica Aplicada
